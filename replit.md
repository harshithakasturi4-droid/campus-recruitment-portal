# PlaceMate

A campus placement portal with a React demo frontend and an Express API foundation.

## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server on `http://localhost:8080` by default; override with `API_PORT`
- `pnpm --filter @workspace/placemate run dev` — run the frontend on `http://localhost:5173` by default; override with `FRONTEND_PORT`
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run generate` — generate Drizzle SQL migrations from the schema
- Local environment values belong in the repository-root `.env` file (ignored by Git). Do not commit credentials; configure production secrets in the hosting provider's environment settings.
- `DATABASE_URL` must be a PostgreSQL connection URI in the form `postgresql://USER:PASSWORD@HOST:5432/DATABASE`. The DB package uses Drizzle ORM with the `pg` node-postgres driver. Create a separate development database and use its URL; do not point local development or schema pushes at production.
- The Drizzle config loads the root `.env` when present. The API dev command also loads it. Frontend configuration loads root env files but exposes only `VITE_` values to browser code; `VITE_API_BASE_URL` defaults to `http://127.0.0.1:8080`, and may be empty for same-origin API requests.
- The frontend binds to loopback by default and allows only localhost hostnames. Configure `HOST` and the comma-separated `DEV_ALLOWED_HOSTS` explicitly for a trusted remote development environment.
- Student numbers are generated by PostgreSQL and use `PM-YYNNN`. Supported graduation years are 2000–2099 so the two-digit year remains unambiguous; a student’s graduation year and number are immutable after creation. Use `insertStudentProfile` from `@workspace/db` rather than calling Drizzle `.values()` directly for student profiles. Migration `0001` deterministically backfills existing profiles by graduation year and UUID order and initializes each year’s counter. Review and apply migrations only through the migration SQL; Drizzle schema push does not install the custom triggers.

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- API: Express 5
- DB: PostgreSQL + Drizzle ORM
- Validation: Zod (`zod/v4`), `drizzle-zod`
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)
